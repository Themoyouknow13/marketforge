● MarketForge Production Architecture

Point-in-time market intelligence → claim/evidence ledger → fail-closed website and X publishing

Deterministic truth

Source snapshots, timestamps, financial calculations, Bayesian math, Monte Carlo results, and publish approval are owned by code—not LLM prose.

Bounded agents

Agents rank, interpret, and write from exact input contracts. They return structured claims and cannot silently enrich missing data.

Fail-closed release

The site and X pipeline consume only approved immutable bundles. Corrections create a new revision and preserve the old one.
